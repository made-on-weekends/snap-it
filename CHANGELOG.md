# Changelog

All notable changes to SnapIt will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-26

### Added
- Initial public release of SnapIt Manifest V3 Chrome Extension.
- Chrome DevTools Protocol (`Page.captureScreenshot`) for high-fidelity full-page scrolling captures.
- Viewport capture and single-click tab snapping.
- Sequential bulk URL queue capture engine with configurable delay intervals.
- Integrated Canvas Annotation Studio with drawing tools (pen, arrows, rectangles, ellipses, text, highlighter, solid redactions, crop, and undo/redo).
- Native File System Access API integration and `chrome.downloads` fallback for automatic folder exports.
- Options and configuration management page for format (PNG/JPEG/WebP), image quality, and capture delays.
- Complete documentation suite, design tokens, brand specs, and agent briefing packets.
