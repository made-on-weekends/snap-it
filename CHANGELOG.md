## [Unreleased]

## [1.0.0] - 2026-10-29

### Added
- High-speed website screenshot tool for Chromium and Firefox.
- Viewport capture, full-page scrolling capture via CDP, and interactive area crop.
- Integrated canvas annotation studio with drawing, arrows, shapes, text, steps, and redaction (blur/pixelate/blackout).
- Bulk URL queue processing and sequential capture automation.
- Multi-engine storage (Chrome Downloads API & File System Access API with IndexedDB persistence).
